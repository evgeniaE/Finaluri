# Finaluri Selenium Automation Project

## About Project

This is my final automation project created with Java and Selenium WebDriver.

The project uses Page Object Model (POM) design pattern and TestNG for test execution.

## Website

https://www.demoblaze.com/

## Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- Rest Assured
- Log4j2
- Extent Reports

## Project Structure

- pages - page classes
- driver - browser setup
- config - configuration
- tests - test cases
- reports - test reports

## Tests

Implemented tests:

- Login test
- Wrong username test
- Wrong password test
- Logout test
- Add to cart test
- API test

## Reports

Extent Reports are used for test results.

## How to Run

Run tests using Maven:

mvn test
